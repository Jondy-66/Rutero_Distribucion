# Routix: Planificación y Gestión Avanzada de Rutas
![Next.js](https://img.shields.io/badge/Next.js-white?style=flat&logo=next.js&logoColor=black)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat&logo=typescript&logoColor=white)

![Firebase](https://img.shields.io/badge/Firebase-FFCA28?style=flat&logo=firebase&logoColor=black)

Routix es una aplicación web construida con Next.js y Firebase, diseñada para optimizar la planificación y gestión de rutas de venta y cobranza. Permite administrar clientes, planificar rutas, asignar usuarios y visualizar ubicaciones en un mapa interactivo para una logística eficiente.

Para una descripción técnica detallada de la arquitectura, el stack y las funcionalidades, consulta el [Manual Técnico](MANUAL_TECNICO.md).
